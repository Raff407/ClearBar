**ClearBar 1.0.0**: a tiny, private way to make the Windows 11 taskbar see-through or softly blurred.

### Install
1. Download `ClearBar-v1.0.0-x64.zip` below and extract it.
2. Double-click `Install.cmd`. No admin needed. It starts with Windows from now on.

Uninstall at any time from *Settings → Apps → Installed apps → ClearBar*, or with `Uninstall.cmd`. Settings live in `%LOCALAPPDATA%\Programs\ClearBar\config.ini`.

### What's in it
- `clear`, `blur` (real Gaussian blur, strength 1–50, works with Transparency effects off) and `normal` looks
- Per-mode looks: desktop / visible window / maximised window / Start / Search / Task View, per monitor
- Show or hide the Windows 11 taskbar line per mode
- About 1.4 MB RAM and no measurable idle CPU; no network code, no telemetry

Requires Windows 11 (build 22000+), x64 (ARM64 not supported yet). The binaries are built by GitHub Actions from this tag; check the download against the `.sha256` file.
