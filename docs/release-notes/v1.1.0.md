**ClearBar 1.1.0** adds **Windows 10** support: the same clear and blurred taskbar looks, now on Windows 10 version 2004 to 22H2 as well as Windows 11.

### Install
1. Download `ClearBar-v1.1.0-x64.zip` below and extract it.
2. Double-click `Install.cmd`. No admin needed. It starts with Windows from now on.

Already on 1.0? Run the new `Install.cmd`; your `config.ini` is kept.

### What's new
- **Windows 10 (build 19041-19045, including LTSC 2021):** `clear`, `blur` and `normal`, every dynamic mode (desktop / window / maximised window / Start / Search / Task View), per monitor.
  - Same tiny footprint: in the Windows 10 VM, 1.1 MB private memory, one thread, 0 ms CPU over 60 s idle.
  - Nothing is loaded into Explorer on Windows 10: `ClearBar.exe` sets the taskbar's accent policy itself and puts it back after shell events that make Explorer redraw its own look.
  - Differences from Windows 11: `blur` uses Windows 10's own blur, whose strength is fixed; there is no top line, so `show_line` does nothing. If ClearBar is killed (not closed), the taskbar keeps its look until Explorer next redraws it.
- The installer accepts Windows 10 2004-22H2 and refuses Windows Server and older Windows 10 builds with a clear message.
- New build check (`tests/import_check.py`) so a future change can't silently break loading on Windows 10.

### Windows 11
Unchanged from 1.0.0. `ClearBarTap.dll` is byte-identical to 1.0.0's, so upgrading does not restart Explorer.

### Tested
- Windows 11: the 1.0 live suites on a clean Windows 11 24H2 (26100) sandbox give the same results as 1.0.0 (blur suite 9/9; keyboard suite 19/20, the one failure being a virtual-desktop check that 1.0.0 also fails in that sandbox).
- Windows 10: a new live suite (`tests/vm/win10_live.ps1`) on a Windows 10 22H2 (19045) virtual machine, including ~60 Hz sampling of the taskbar while Start, Search, Action Center, Alt+Tab, theme and transparency changes happen. Not yet tested on physical Windows 10 hardware.

Requires x64 (ARM64 not supported yet). The binaries are built by GitHub Actions from this tag; check the download against the `.sha256` file.
